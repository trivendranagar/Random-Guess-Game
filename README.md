# 🎯 Random Guess Game

A simple number guessing game built using **HTML, CSS, and JavaScript**.

The game generates a random number, and the player has to guess the correct number. After each guess, the game provides feedback to help the player reach the correct answer.

## 🚀 Features

* Generates a random number
* Takes user input for the guess
* Provides feedback for each guess
* Tracks the number of attempts
* Simple and beginner-friendly interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🎮 How to Play

1. Enter a number in the input field.
2. Click the **Guess** button.
3. The game will tell you whether your guess is:

   * Too high
   * Too low
   * Correct
4. Keep guessing until you find the correct number.

## 💻 How to Run

### Option 1 — Open Directly

1. Clone the repository:

   ```bash
   git clone https://github.com/trivendranagar/random-guess-game.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

### Option 2 — VS Code

Open the project in VS Code and use **Live Server** to run the game in your browser.
